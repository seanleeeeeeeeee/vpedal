A computer vision device that creates a virtual MIDI pedalboard below any piano.

- Runs with OpenCV on Raspberry Pi 5 with IMX219 and similar cameras (change your config.json accordingly)
- Straightforward setup: set corner points, contour parameters adjusted semi-automatically
